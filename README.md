# SipSpot

A premium static landing page for a cafe explorer website with a full-screen video background, modern glassmorphism UI, and responsive layout.

## Files

- `index.html` — landing page structure
- `styles.css` — premium dark theme styling and responsive design
- `script.js` — lightweight navigation interactivity

## Run locally

Open `index.html` in your browser to view the cafe explorer landing page.

## Notes

- The background uses a remote video source for a cafe ambience experience.
- The design is optimized for mobile and desktop with polished spacing and typography.
